================================================================================
                    1. IMAGE OPTIMIZATION
================================================================================

A. Lazy Loading
--------------------------------------------------------------------------------
Add loading="lazy" to all below-fold images:

  <img src="image.jpg" loading="lazy" alt="...">

Already optimized:
  - Logo images (header): Keep preload
  - Below-fold images: Add lazy loading
  - Background images: Use CSS background-image

B. Image Formats
--------------------------------------------------------------------------------
Current: PNG/JPEG
Recommended:
  - Use WebP for all images (40-60% smaller)
  - Use AVIF where supported (even smaller)
  - Tools: sharp, squoosh, cwebp

Command to convert:
  cwebp -q 80 input.png -o output.webp

C. Responsive Images
--------------------------------------------------------------------------------
Use srcset for different screen sizes:

  <img src="image-800.jpg"
       srcset="image-400.jpg 400w,
               image-800.jpg 800w,
               image-1200.jpg 1200w"
       sizes="(max-width: 600px) 100vw,
              (max-width: 1200px) 50vw,
              33vw"
       alt="...">

D. Preconnect & Prefetch
--------------------------------------------------------------------------------
Add to <head>:

  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link rel="dns-prefetch" href="https://www.google-analytics.com">

================================================================================
                    2. FONT OPTIMIZATION
================================================================================

A. Font Display Swap
--------------------------------------------------------------------------------
Already implemented with font-display:swap

  font-family: 'Inter', sans-serif; /* fallback */
  font-family: 'Inter', sans-serif;
  font-display: swap;

B. Subset Fonts
--------------------------------------------------------------------------------
Use only needed character sets:

  <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap&subset=latin">

C. Variable Fonts
--------------------------------------------------------------------------------
Consider using variable fonts (1 file instead of 6):

  # Instead of 6 weights, use 1 variable font
  font-variation-settings: 'wght' 400..700;

D. Font Preloading
--------------------------------------------------------------------------------
Preload critical fonts only:

  <link rel="preload" href="/fonts/inter-var.woff2" as="font" type="font/woff2" crossorigin>

================================================================================
                    3. CSS OPTIMIZATION
================================================================================

A. Critical CSS
--------------------------------------------------------------------------------
Inline critical CSS in <head> for above-fold content:

  <style>
    /* Critical CSS here */
    body { margin: 0; font-family: Inter, sans-serif; }
    .hero { min-height: 100vh; display: flex; }
  </style>

B. Async CSS Loading
--------------------------------------------------------------------------------
Load non-critical CSS asynchronously:

  <link rel="preload" href="/styles.css" as="style" onload="this.onload=null;this.rel='stylesheet'">
  <noscript><link rel="stylesheet" href="/styles.css"></noscript>

C. CSS Minification
--------------------------------------------------------------------------------
Already minified if using Vercel.

For manual optimization:
  - Remove unused CSS
  - Use CSS containment where applicable
  - Avoid expensive selectors (deep nesting)

--------------------------------------------------------------------------------

  <script src="/effects.js" defer></script>

B. Dynamic Imports
--------------------------------------------------------------------------------
Lazy load non-critical features:

--------------------------------------------------------------------------------

D. Event Listener Optimization
--------------------------------------------------------------------------------
Use passive listeners for scroll/touch:

  window.addEventListener('scroll', handler, { passive: true });

Already done in effects.js - verify all scroll listeners are passive.

================================================================================
                    6. RENDER OPTIMIZATION
================================================================================

A. Reduce CLS (Cumulative Layout Shift)
--------------------------------------------------------------------------------
Add dimensions to all images:

  <img width="400" height="300" src="..." />

Reserve space with aspect-ratio:

  .image-container {
    aspect-ratio: 4 / 3;
    background: var(--border); /* placeholder */
  }

B. Avoid Layout Shifts from Fonts
--------------------------------------------------------------------------------
Use font-display: swap (already done)

Use size-adjust for fallback:

  @font-face {
    font-family: 'Inter Fallback';
    src: local('Arial');
    size-adjust: 107%;
    ascent-override: 90%;
    descent-override: 25%;
  }

C. Virtualize Long Lists
--------------------------------------------------------------------------------
If adding testimonials/projects, use virtualization:
  - react-window
  - @tanstack/virtual

================================================================================
                    9. ANIMATION PERFORMANCE
================================================================================

A. Use transform/opacity Only
--------------------------------------------------------------------------------
Only these properties can be animated cheaply:

  ✅ transform: translateX(), scale(), rotate()
  ✅ opacity
  ❌ Avoid: width, height, margin, padding, top, left

B. Will-Change
--------------------------------------------------------------------------------
Add for animated elements:

  .animated-element {
    will-change: transform, opacity;
  }

  /* Remove after animation completes */
  element.style.willChange = 'auto';

C. GPU Acceleration
--------------------------------------------------------------------------------
Force GPU for specific elements:

  .blur-element {
    transform: translateZ(0);
    backface-visibility: hidden;
  }
